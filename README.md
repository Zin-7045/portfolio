# Portfolio — Abdur Rehman

Personal portfolio website showcasing projects in Data Science, AI, Big Data, and Blockchain.

Built with HTML, CSS, and JavaScript. Deployed via Netlify.

## Sections

- **Home** — Animated hero with typewriter effect and code window
- **About** — Stats grid and bio
- **Skills** — Animated progress bars across 4 categories
- **Projects** — DISHBRAIN (AI/RAG), Sentinel (Big Data), BookinPK (Web3)
- **Contact** — Email, LinkedIn, GitHub links
